# 📖 Capítulo 003

# Títulos y párrafos

En este capítulo comenzaremos a agregar contenido a nuestra página utilizando títulos y párrafos.

Estas son las etiquetas que utilizarás en prácticamente cualquier sitio web.

---

# 🎯 ¿Qué aprenderás?

- Para qué sirven los títulos.
- Qué diferencia existe entre `<h1>` y `<h6>`.
- Cómo escribir párrafos.
- Buenas prácticas de organización del contenido.

---

# Los títulos

HTML dispone de seis niveles.

| Etiqueta | Uso recomendado |
|----------|-----------------|
| `<h1>` | Título principal de la página |
| `<h2>` | Secciones principales |
| `<h3>` | Subsecciones |
| `<h4>` | Nivel secundario |
| `<h5>` | Nivel terciario |
| `<h6>` | Menor jerarquía |

---

# Los párrafos

Para escribir texto utilizamos:

```html
<p>Este es un párrafo.</p>
```

Cada párrafo representa una idea o bloque de contenido.

---

# Buenas prácticas

- Utilizar un solo `<h1>` por página.
- Mantener una jerarquía lógica (`h1` → `h2` → `h3`...).
- No utilizar títulos únicamente para cambiar el tamaño del texto.
- Utilizar `<p>` para el contenido y no insertar saltos de línea innecesarios.

---

# Resultado esperado

La página mostrará varios niveles de títulos junto con sus respectivos párrafos, organizando el contenido de forma clara y semántica.

---

# 💡 Ejercicio

Crear una página que contenga:

- Un `<h1>`.
- Dos `<h2>`.
- Un `<h3>`.
- Cuatro párrafos.

Organizar el contenido respetando la jerarquía de títulos.

---

# 📌 ¿Sabías que?

Google utiliza la estructura de títulos para comprender mejor el contenido de una página.

Una jerarquía correcta mejora tanto la accesibilidad como el SEO.
